### Key Discovery: Dual-CRS Reprojection Approach

When a piece must fit neighbors in **two different projections** (e.g., Borneo borders Indonesia in seasia CRS but ocean borders Philippines in eurasia CRS), blending projections creates mesh distortion. The solution:

1. **Build land mesh** from the DEM that has coverage (seasia for Borneo)
2. **Reproject vertices** to the target CRS (eurasia) via WGS84 round-trip
3. **Build ocean mesh** directly in the target CRS
4. **Combine** — all output in one CRS, fits target neighbors perfectly

**Trade-off**: The reprojected land border has ~6mm shape mismatch with the other-CRS neighbor (Indonesia), vs ~42mm mismatch if you kept the wrong CRS for ocean. The 6mm is acceptable for 3D printing; 42mm is not.

See `DUAL_CRS_REPROJECTION.md` for the full technical writeup.

### Coordinate Convention
Two STL conventions exist (documented in `align_seasia_eurasia.py`):
1. **Mainland** (`is_mainland=True`): x_min shifted to 0, `cx = east_edge - stl_x / scale`
2. **Ocean/special** (`is_mainland=False`): origin at x=0, `cx = origin_x - stl_x / scale`
